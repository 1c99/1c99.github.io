DeepCatch X (X-ray) [details]
  • Presented DeepCatch X at NVIDIA GTC 2025 (exhibitor), demonstrating diffusion-based organ extraction and clinical quantification from CXR.
  • Developed a Conditional DDPM for X-ray-to-aorta extraction (Dice = 0.97, outperforming the GAN baseline) that outperformed radiologists on aortic-dilation detection (Sensitivity 0.93 vs 0.31); trained on 4-GPU DDP with FP16 mixed precision.   • Engineered a Ray-distributed inference pipeline (14-module DAG of actors) with a VLM-driven PA-view pre-filter; achieved 100x daily throughput and 2.8x per-case speedup via adaptive scheduling, shared memory, and TensorRT / ONNX / FP16 optimization. Applied to 2.3M+ cases.
  • Built a CI/CD-driven on-premise deployment pipeline for collaborative hospital research — reduced production codebase by 76% in LoC and compiled into source-encrypted standalone executables.
  • Ported the BioAge pipeline from research-grade R to production C++ with numerical equivalence; deployed across check-up centers.
  • Led end-to-end acquisition of 100TB+ medical datasets through multiple data vendors for FDA / MFDS regulatory submissions.
3D FaceLandmark and AR Registration for EVD Surgical Navigation [details]
  • Built a 3D spatial perception pipeline from volumetric CT — patient-specific skin-surface segmentation, 2D landmark detection, and ray tracing to lift 2D landmarks into 3D reference points.
  • Implemented real-time 6-DoF pose estimation between preoperative CT landmarks and an intraoperative iPad Pro LiDAR point cloud using statistical outlier removal (k-NN) followed by Kabsch + ICP; achieved FRE = 1.8 mm, supporting MFDS regulatory documentation.
  • Co-developed with iOS engineers to deploy the full registration pipeline on-device for real-time operating-room use.
LLM-based De-Identification System and Translation with Agentic Systems [details]
