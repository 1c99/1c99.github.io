PHI De-Identification Pipeline

Medical data needs strict HIPAA/GDPR compliance to be shared for research and collaboration — but Protected Health Information (PHI) hides across many modalities: burned-in text on images, DICOM metadata, PDFs, and handwritten annotations. This system removes it automatically, where manual de-identification is slow and error-prone.

98% detection LLM OCR NER DICOM

Two-Pronged Approach

📄 Metadata Anonymization
LLM parses DICOM headers to identify PHI fields (Patient Name, ID, Birth Date) and generates consistent anonymized mappings while preserving non-PHI metadata.
🖼️ Burn-in Text Detection
OCR extracts text regions with bounding boxes. LLM/NER classifies each as PHI or non-PHI. Pixel-level black mask applied over PHI while preserving markers (L/R, PA).

Multilingual Translation System

Four role-specialized models — Translator, Reviewer, Fixer, and Supervisor — draft, review, correct, and sign off each translation, with an independent terminology check guarding clinical terms. Translating the product’s content opened it to new international markets.
