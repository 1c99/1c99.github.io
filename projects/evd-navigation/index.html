Overview

External Ventricular Drainage (EVD) is a critical neurosurgical procedure requiring precise catheter placement. This system uses AR-assisted navigation to register preoperative CT scans to the patient’s actual anatomy in real-time, helping surgeons accurately position the drainage catheter.

3D Facial Landmark Extraction

The FaceLandmark approach originated from a related 3D medical visualization project, where I handled visualization, quality assurance, and data management for CT-reconstructed head meshes. Working with these 3D models led to developing a markerless landmark extraction pipeline that was later integrated into the EVD navigation system.

Building on this experience, I led the development of a markerless pipeline that automatically identifies anatomical landmarks from head CT scans, combining 2D facial landmark detection with ray tracing for 3D reconstruction. In the OR, a two-stage 6-DoF pose estimation aligns preoperative landmarks to the live patient: Kabsch (SVD) for coarse alignment, then ICP (point-to-plane) for sub-millimeter refinement. The entire pipeline runs in real-time on an iPad Pro, co-developed with iOS engineers for intraoperative deployment.

ISO Phantom Validation

Accuracy was validated against an ISO-defined phantom model with physically measured ground truth coordinates. The ground truth required precise manual measurement of landmark positions on the phantom — a painstaking process repeated across multiple trials for statistical significance. The system achieved FRE < 2mm on 100% of test cases, meeting the regulatory threshold for MFDS submission.

Key Challenges Solved

Coordinate Alignment
CT scanner and iPad LiDAR use different coordinate systems — unified into a common reference frame.
LiDAR Noise
Statistical outlier removal (k-NN distance threshold) for clean point cloud reconstruction.
Scale Differences
Medical STL files and LiDAR scans normalized to a common scale for accurate overlay.
Correspondence
Automatic landmark matching between source CT and target patient anatomy.
