Data Acquisition & Management

International Data Vendors

Supplementary datasets were sourced from international medical data platforms to meet project requirements: demographic diversity (ethnicity, sex, height/weight), scan conditions (slice thickness, chest coverage), and clinical balance (normal vs. disease). End-to-end acquisition of 100TB+ supported FDA / MFDS regulatory submissions, requiring rigorous documentation of dataset provenance and balance.

Segmed

Research Innovation

The core research contribution is a conditional diffusion model that extracts 2D aorta projections from X-rays. A 3D volumetric extension via Latent Diffusion with a 3D VAE, Flash Attention, and window attention for local context is proposed.

Training uses a ConcatConditionedUNet with noise prediction objective (MSE loss), conditioned on X-ray input via channel concatenation. 4-GPU DDP training (NCCL) with gradient accumulation (effective batch size 512), mixed precision (FP16 + GradScaler), and cosine LR schedule with warmup.

Inference Optimization

Hospital datasets arrive on physical SSDs — terabytes of DICOM files with no API endpoint. The Ray-based pipeline orchestrates 14 modules as a DAG of independent actors with automatic scheduling and zero-copy data sharing. A VLM-driven pre-filter inspects incoming DICOMs and routes only valid PA-view chest X-rays into the pipeline, eliminating wasted compute on incompatible studies.

Large-Scale Processing

Beyond scheduling, the system includes layers of hardening that enable reliable processing of 2.3M+ files across multi-day runs: adaptive weight management with two loading strategies, memory-bounded workers with automatic respawn, and crash-safe persistence via CSV state logs and atomic writes.

Production Engineering

Shipping deep learning to hospitals means standalone executables, no Python runtime, and IP-protected binaries. A major refactoring effort eliminated dead code and unified the architecture before Nuitka compilation.

3D Facial Landmark Extraction

The FaceLandmark approach originated from a related 3D medical visualization project, where I handled visualization, quality assurance, and data management for CT-reconstructed head meshes. Working with these 3D models led to developing a markerless landmark extraction pipeline that was later integrated into the EVD navigation system.

Building on this experience, I led the development of a markerless pipeline that automatically identifies anatomical landmarks from head CT scans, combining 2D facial landmark detection with ray tracing for 3D reconstruction. In the OR, a two-stage 6-DoF pose estimation aligns preoperative landmarks to the live patient: Kabsch (SVD) for coarse alignment, then ICP (point-to-plane) for sub-millimeter refinement. The entire pipeline runs in real-time on an iPad Pro, co-developed with iOS engineers for intraoperative deployment.

ISO Phantom Validation

Accuracy was validated against an ISO-defined phantom model with physically measured ground truth coordinates. The ground truth required precise manual measurement of landmark positions on the phantom — a painstaking process repeated across multiple trials for statistical significance. The system achieved FRE < 2mm on 100% of test cases, meeting the regulatory threshold for MFDS submission.

PHI De-Identification Pipeline

Medical data needs strict HIPAA/GDPR compliance to be shared for research and collaboration — but Protected Health Information (PHI) hides across many modalities: burned-in text on images, DICOM metadata, PDFs, and handwritten annotations. This system removes it automatically, where manual de-identification is slow and error-prone.

98% detection LLM OCR NER DICOM

Two-Pronged Approach

📄 Metadata Anonymization
LLM parses DICOM headers to identify PHI fields (Patient Name, ID, Birth Date) and generates consistent anonymized mappings while preserving non-PHI metadata.
🖼️ Burn-in Text Detection
OCR extracts text regions with bounding boxes. LLM/NER classifies each as PHI or non-PHI. Pixel-level black mask applied over PHI while preserving markers (L/R, PA).

Multilingual Translation System

Four role-specialized models — Translator, Reviewer, Fixer, and Supervisor — draft, review, correct, and sign off each translation, with an independent terminology check guarding clinical terms. Translating the product’s content opened it to new international markets.
